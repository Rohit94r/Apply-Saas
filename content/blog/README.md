# Blog content (SEO)

Edit **`posts.ts`** only.

Each post needs:
- `slug` — URL path `/blog/[slug]`
- `title`, `description` — meta tags + Open Graph
- `targetKeyword` + `keywords[]` — Google Search Console targets
- `sections[]` — article body

**Do not** change routing in `app/blog/` unless adding new page types.
